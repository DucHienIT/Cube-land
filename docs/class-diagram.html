Cube Blaster — Class Diagram

Toàn bộ hệ thống code first-party trong Assets/_Project/Scripts/ · namespace CubeBlaster

Kiến trúc: MonoBehaviour mỏng (giữ serialized ref + Unity lifecycle) → uỷ quyền cho plain class; mọi collaborator đi qua interface; service thiếu thì rơi về Null-Object.

1 · Sơ đồ quan hệ tổng thể

MonoBehaviour interface plain class static facade ScriptableObject struct / enum abstract owns / creates implements / uses

Bấm vào một node để chỉ hiện các quan hệ của nó — bấm nền để bỏ chọn. Gõ vào ô tìm kiếm sẽ highlight node khớp.

2 · Luồng chạy chính

  1. Boot — GameBootstrap ([DefaultExecutionOrder(-100)]) nạp 3 config asset vào locator GameConfig.Active / PaletteConfig.Active / VisualLibrary.Active, bật post + SMAA, set ambient/light.
  2. Start — GameManager.Start() → UIController.Initialize(this as IGameFlow) → dựng 5 screen (ẩn) → ShowMainMenu().
  3. StartLevel(n) — LevelLibrary.Load(n) (Resource → fallback Procedural) → new VoxelModel(data) → SculptureView.Initialize(model, palette) → new ExposedTargetSelector(model, new CameraVoxelVisibility(...)) → BuildSlots() → BankArea.Initialize() → BoardInput.Initialize(this as IBoardContext) → CameraRig.FitTo(bounds).
  4. Input — BoardInput chỉ định tuyến: gesture đầu tiên TryBegin() thắng. BlockDragGesture (kéo block hàng 0 → deploy / tap → slot trống đầu) hoặc TurntableGesture (xoay bàn xoay).
  5. Deploy — IBoardContext.DeployBlock(block, slot) → chặn nếu màu đó đã hết voxel → GunSlot.Deploy(ammo, colorIndex) → sinh Gun.
  6. Bắn — Gun tự động gọi IShooterContext.RequestTarget(color) → selector reserve voxel lộ ra camera → SpawnDart(index, muzzle, barrel.forward). Gun về hưu khi CountAliveOfColor()==0 dù còn đạn.
  7. Trúng — Dart bay theo DartArc (bezier rời nòng → bổ theo tia camera) → IDartContext.ResolveDartHit() → targets.Release() + VoxelModel.DestroyVoxel().
  8. Phản hồi — event VoxelDestroyed → SculptureView chạy DestructionEffects (flash/burst/shards/puff qua IFxService), FragmentEmitter (debris pooled), VoxelCubeField.PunchAround() (punch + flash hàng xóm), CameraRig.Rig.Shake().
  9. Thắng — event AllCleared → IStarRule.Evaluate() → SaveSystem (stars/coins/unlock) → UIController.ShowWin().
